# Collection → EASY: local media leverage

Collection already identifies **rembg** for local background removal and **Upscayl** for local upscaling as EASY Creative leverage.

EASY now records them as optional capability adapters. This layer does not claim that either binary is installed or that an execution occurred.

Execution remains fail-closed and must produce runtime evidence before being called successful.

The adapters inherit Product Integrity: color, logo, printed text/letters/numbers, brand name, shape, major components and distinctive details must remain unchanged.
