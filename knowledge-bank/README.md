# EASY Knowledge Bank

This is a broad, provider-neutral knowledge and discovery bank for EASY and for future projects.

## Scope

The bank is intentionally broader than EASY. It tracks useful resources across:
- AI, LLMs, multimodal models, agents and MCP
- APIs and API directories
- open-source software and self-hosting
- datasets, model hubs and benchmarks
- research papers and technical references
- developer tools, SDKs and infrastructure
- e-commerce, marketing, advertising and social platforms
- search, scraping, browser automation and data extraction
- payments, logistics, maps and communications
- security, privacy and compliance
- education and learning resources
- business, finance and analytics
- design, media, image/video/audio tooling
- robotics, IoT, science, engineering and emerging technology

## Selection rule

Prefer official documentation and actively maintained repositories. Record licensing, commercial-use restrictions, authentication, pricing/free tier, rate limits, privacy/data retention, reliability, maintenance status and practical usefulness when known.

Do not treat a directory listing as proof that a provider is production-ready. Verify important providers individually before integration or commercial use.

## Security rule

Never store API keys, access tokens, passwords, private credentials, cookies, seed phrases or other secrets in this repository.

## Architecture rule

For software integrations, use adapters/interfaces so providers can be replaced without redesigning the product.

## Maintenance

This bank is a living index, not a claim that every listed resource has been exhaustively evaluated. Add useful discoveries continuously and promote only verified/high-value items into EASY implementation plans.
