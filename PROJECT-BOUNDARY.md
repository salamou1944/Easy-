# EASY Project Boundary

This repository owns the EASY commerce product: seller/product intake, Product DNA, product-integrity validation, creative generation interfaces, seller-facing workflow, persistence contracts, and product UI.

MONY / Revenue Engine experiments do not belong here. Affiliate revenue, sales campaigns, prospecting, payment experiments, and revenue-engine state must remain in their dedicated project/repository.

Prototype mode is explicitly non-production. A production claim requires a real provider adapter, durable persistence, authentication/authorization, observable request IDs, integrity validation, and an end-to-end test against the deployed service.
